## PROPOSED / 不应强行当成用户已经同意的方案

- `RewardService`, `SaveRepository`, `SceneBridge` 等具体类名、编码文件夹分层、Schema 验证库选型与散列字节序：作为实现建议，允许在 R1 通过 ADR 优化。
- NPC 逐句俄语对白文学修订、物品名称、猫咪建议名字及输入长度：可保持已有草案的可执行默认值，但不应宣称正式美术/配音完成。
- 首次整理贴纸具体图样、三个不同日期纪念贴纸：供 DEMO 验证的候选内容，可依用户后续意见替换。
- R0–R8 阶段顺序可按已有工程与依赖调整，但每项功能与验收要求不能删。

## PENDING_USER_INPUT — 由制作人另行提交

- Home 正面广角设计稿、逻辑画布、分层/关键对象与四藏点世界坐标；预渲染/插画素材实际交付。
- 城市大地图构图、六个入口的实际画面坐标与热点/镜头边界。
- 完整竖屏 HUD 和独立整理、换装、手账、对话视觉；互动布局规则。
- 真正可导入的艺术资源。没有这些输入，核心逻辑可以先做，场景/视觉最终验收不得通过。

## UNVERIFIED — 没有证据的工程事实

当前没有证据证明新的 Codex 游戏仓库已创建、依赖安装成功、任何旧 Agent 工作树已合并、浏览器测试通过或付费资源已购买；每一项只能由 R0 审计/实际测试确定。

## 冲突处置

每次新决定追加新的明确条目与更新日期，并将被取代的旧规则标为 `SUPERSEDED`；严禁将同一功能的两个历史行为同时保留。不能因为引用 V0.2 的“衣柜/家具点击整理”或“床窗二选一”而覆盖本表。
