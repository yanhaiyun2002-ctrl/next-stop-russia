# ADR 0001：P0-01 引擎、地图与布局边界

日期：2026-10-28。状态：采纳，仅 P0-01。

## 背景与决定

技术审查未发现明确引擎阻碍。固定 Godot 4.7.2 Stable + GDScript + Compatibility；安装障碍单独记录，不静默换版本。主工程入口挂载地图场景；地图发出建筑 ID，主入口负责验证与场景切换，宿舍/学校是独立临时场景。Resource 保存 ID、名字、位置、目的路径和开放状态。地图保留在树中并在室内隐藏，返回恢复同一实例和焦点，无磁盘存档。

横屏采用 1280×720 布局基准，竖屏采用 360×780 布局基准；只做等比 UI 缩放，地图区域按方向重新映射建筑位置。Control 容器承载标题、提示、返回与交互，安全区转换后加边距。只采用 GUI 按钮的 pressed 语义，触摸模拟鼠标开启，反向模拟关闭；转换期间拒绝重复导航。

## 后果与限制

同一建筑配置和导航可在两种方向复用，但不强求正式地图拥有同一构图。当前三栋楼不需平移/缩放；以后地图变大时先验证相机、热点与状态恢复，再扩展。2D 房间层次、局部 3D、玩法状态、长期存档和通用小游戏生命周期不在此 ADR 固化。

DEMO 与正式版共用主工程；未来按构建配置与显式资产清单隔离，不复制代码库。P0 没有正式资产，暂不增加空的发布系统。

## 被放弃的本阶段方案

不为未知玩法建立全局服务集合；不在布局中硬编码场景跳转；不将横屏整图非等比拉伸为竖屏。独立场景保持小规模，只有实际重复出现后再抽象。
