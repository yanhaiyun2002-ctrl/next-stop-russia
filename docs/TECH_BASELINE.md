# 技术基线与待验证决定

状态：P0 候选技术基线（不是所有平台已验证的结论）

| 项目 | 基线 |
|---|---|
| 引擎 | Godot 4.7.2 Stable；启动工作前核对版本安装与可用性 |
| 开发语言 | GDScript |
| 渲染 | Compatibility 为初始候选；复杂空间表现按原型复核 |
| 游戏画面 | 2D 分层优先；局部 2.5D/3D 不排除 |
| PC | Windows、macOS；横屏优先；1280×720 为 UI 布局参考 |
| 手机 | Android、iOS；竖屏优先；采用独立竖屏布局基准，不等同缩放 PC 画面 |
| 输入 | 鼠标与触摸共享导航语义；避免事件重复触发 |
| 仓库 | Git；不擅自远程推送 |
| 构建 | 同一主工程；未来 DEMO 与正式版以构建配置和实际打包资产区别 |

## 必须核实的事实

- 官方文档及当前环境支持的 Godot 引擎版本与导出模板。
- Android 导出要求、SDK/签名依赖；iOS 需要 macOS/Xcode 及对应签名流程。
- 不把引擎支持、构建成功、真机运行混为一谈。
- 手机刘海/安全区域、不同纵横比、后台恢复及基本性能预算。

## 技术约束

- 最小可维护模块化单体主工程；不建立微服务式架构。
- 当前实现地图、建筑独立场景、基础导航与输入/布局；P0-03 另经任务书授权加入正视广角宿舍空间灰盒，仍使用同一个主工程与 2D Compatibility 基线。
- 不实现正式剧情、俄语学习、找猫、整理、商店、经济、宠物成长、复杂存档或联网服务。
- 后续具体玩法经原型验证后接入共享工程。
