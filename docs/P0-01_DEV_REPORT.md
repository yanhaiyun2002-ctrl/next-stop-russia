## 实际实现

- 启动主入口即显示第一层级地图。三栋建筑采用临时图形与文字，不决定正式地图内容。
- 宿舍、学校分别载入独立 `.tscn`，各提供查看门牌/告示的简单交互与返回按钮；商店保留锁定状态并反馈。
- `BuildingDefinition` 原生 Resource 保存稳定 ID、名字、归一化地图位置、目的场景路径、开放状态。
- 地图 UI 只发出 ID；导航模块验证开放状态、错误 ID/路径和场景接口，转换锁防止重复切换；返回复用同一地图实例，恢复建筑选择及焦点。
- 横屏以 1280×720、竖屏以 360×780 为不同布局基准。建筑数据复用，横屏横排、竖屏纵排；容器承载文字与控件、安全区按物理/逻辑坐标换算，UI 等比缩放。
- 鼠标与触摸共享按钮语义，仅开启 touch→mouse，关闭反向模拟；室内按钮、Escape、系统返回通知可回地图。
- 本地 Git 初始化完成，忽略工具、引擎缓存、构建输出与凭据，保留 `.uid`；没有远程、没有自动提交、推送或发布。

实现保持模块化单体，没有自动加载服务集合、万能场景路由或空玩法系统。当前地图没有平移/缩放；当前室内交互计数为临时实例状态，不持久化。
