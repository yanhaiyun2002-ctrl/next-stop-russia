# 《下一站，俄罗斯！》V0.3 设计基线（讨论版）

日期：2026-10-27  
状态：**策划讨论稿；尚未授权 Codex 开发；不代表代码已存在或通过验收**。

## 决策权和优先级
- 以用户最新明确决策为第一优先级；V0.2 是历史合并基线；原 DEMO 美术不允许回用。
- 状态：`LOCKED` 已确认，`PROPOSED` 建议，`PENDING` 待确认，`SUPERSEDED` 被替代，`UNVERIFIED` 代码状态未验证。
- 项目首要目标：剧情驱动逐步解锁内容，已解锁小游戏可自主反复玩；主游戏是俄罗斯留学生活模拟，玩法基于模块化小游戏。
- DEMO 最重要的是框架、可玩性、可维护性及手动试玩，非一次性完成大量正式美术与活动内容。

## LOCKED — 游戏结构与开局
- 玩家初到圣彼得堡，安娜是前期导师式引导、后期长期朋友和主线角色。
- 简化序章直接进入宿舍；完整动态序章后置。
- 首次宿舍：先触发猫咪相遇和找猫，之后剧情引导首次整理，**两项玩法都必须完成才开放离开宿舍进入城市地图**。
- 可以跳过冗长叙事演出，但保留关键操作教程；当前不会默认赋予跳过核心新手任务的权限。提供渐进提示以避免卡死。
- 初期安娜当面互动；后续结合消息与重要事件见面。
- 城市地图初期由主线明确引导，后续开放功能可自主体验；地点锁定状态由剧情条件决定。

## LOCKED — 宿舍与场景
- 当前宿舍视觉采用 **B 正面广角室内展示**：玩家如同站在房间前方向里面看。二维图层实现，不开发真实 3D。
- 房间为比手机视口大的空间，可拖动；独立墙、地板、天花结构表现、门窗、家具、人物/猫、前景遮挡、交互热点。室内空间感与清楚看到家具并重。
- 未来可以增设 A 正面剖视或 D 横向展开的房间形式；核心玩法不绑定某一张透视底图。
- 必需功能家具如床、书桌、衣柜保留固定功能位：不删除、可换款式、在有适配资源时可改朝向；独立装饰/摆件未来可增加、删除和合法摆放。
- 当前 DEMO 仅验证资源按模块替换，**不开发完整装修编辑器**。
- 摄像机：`homeExplore` 可移动；找猫使用同一 HomeScene 切换 `catFit`，交互后恢复视角；屏幕形状变化后热点仍正确。

## LOCKED — 猫咪与找猫 R3.2
- 默认猫咪为**西伯利亚森林猫**，首次称“猫咪”；首次摸猫后**必须立即选择或输入并确认名字**，不提供延期按钮；后续支持其他品种。
- 长期方向：有照顾行为的宠物系统＋轻亲密度；完整养成、品种选择和数值经济不在 DEMO 实现。
- 独立反复游玩，不设计找猫关卡或强制体力消耗。
- 首次玩家看到真实猫咪；猫跑向**床、窗户、衣柜、书桌**任一合法藏点；猫/线索/遮挡/词汇标签共用真实家具数据，不能瞬移。
- **替代旧版 R3.1 固定选择题**：家具附近显示俄语标签；首次同时显示中文，以后俄语优先且随时可查中文。点击对应标签时同次播放俄语并判断；错误不扣分不改变藏点。
- 正确后猫探耳、探头、连续离开家具走至可点击区域；玩家实际摸猫完成反应后才永久授予首次奖励和解锁重玩。一次性奖励必须幂等，刷新不能重复发放。
- 后续可以增加俄语位置短句，须单独校对，不把家具名词误写为位置短语。

## LOCKED — 每日整理
- 采用“轻松收纳＋有逻辑性的轻解谜”：分类条件与简单空间/容量规划都有实际游戏价值；非线性关卡，不设计无穷手工关卡。
- **入口改为宿舍 HUD 独立侧边「整理」图标/按钮**，不再由行李箱或书桌点击进入；此前家具＋任务列表双入口为 `SUPERSEDED`。
- 首次主线通过提示点击侧边入口开始行李整理教程。**每日奖励仅记手账日志及少量纪念贴纸/印章，不产出货币。** 之后按本地自然日提供每天唯一固定的日常任务；当天无论重进或重玩都使用同一题面，次日轮换；不强制连续签到。
- 使用经过验证有解的有限模板池，按日期和题目版本确定性选择；同日重进不改变题目，退出/重复进入不破坏宿舍装修，日常奖励一天只可领取一次（本地实现作为 DEMO）；内容丰富度后续拓展。
- DEMO：少量区域模板、归位与分类/容量规则、简单操作提示、可重玩及本地存档；复杂空间拼箱后置。

## LOCKED — NPC 语言与主线
- 正式人类 NPC 在 DEMO 中仅安娜与宿舍管理员；两位的**俄语对白作为主文本显示，并同时提供中文字幕**，缺失语音不阻塞剧情。玩家内心独白/系统引导可使用中文。
- 玩家第一次去大学为了**领取报到资料**，通过外景资料领取热点完成，不增加学校正式人类 NPC。
- 地图中俄双语切换是独立设置，不能控制 NPC 中文字幕或找猫教学俄语。

## LOCKED — 城市与其他系统
- 大范围圣彼得堡地图，用可信的河道、桥梁、瓦西里岛等地理骨架，允许游戏化距离压缩；可平移与点击建筑，不要求摇杆在全城寻路。
- 初期六入口：我的小屋、大学、咖啡馆、博物馆、教堂、火车站。大学只使用真实相应区域作为位置参考，游戏标签仅称“大学/学校”，不显示真实大学全称。
- 建筑名称支持中文＋俄语双语，设置中可选双语、中文或俄语；语言切换不应关闭找猫的俄语教学。
- DEMO 宿舍开放、大学预告、其他四处锁定。正式地图与六处具体坐标/最终美术后续明确。
- 手机竖屏底栏 HUD＋侧边整理入口；独立衣柜至少 2 外套×2 围巾；独立手账、词汇、贴纸、首次奖励，刷新后保持。
- 体力、收费恢复、俄语学习补充体力、学校课程、商店运营等为长期系统；DEMO 只保留扩展接口，无真实支付/后端。

## 美术与素材策略
- 当前 **暂停临时素材选择**，优先完善 99% 可实施策划书。未来恢复选材时仅提供免费且可直接下载的候选，由用户选择后接入；不推荐付费素材、不擅自购买。临时素材仅在本地开发用途使用，后续公开分发前再解决素材可用性。
- 不重复使用用户否决的旧 DEMO 视觉。《时尚百货城》仅作家装空间/品质与 UI 组织原则参考，不照搬可识别资产。
- 临时游戏资产一律 `TEMP_REPLACE_REQUIRED`，统一登记 `assetId`, 来源链接, 路径, 透视方向, 独立可替换状态。
- 不做逐张手动素材审核作为本地开发流程，但未经授权的网络参考图不得直接打包成可下载/可访问的试玩资产；正式发布必须替换或取得可用授权。
- 对于当前素材包优先检查是否能**单独提取床/窗/衣柜/书桌、遮挡层和不同表观**；一张好看的合成室内图不能假装可编辑家具。

## 技术与协作（建议，待正式接口文件冻结）
- 优先 React + TypeScript + Vite + Phaser 3 + Zustand，统一 SceneBridge / AssetManifest / CameraController / StoryEvents / MinigameRegistry。
- 游戏规则、剧情、词条、本地化、地点、家具实例、藏点、关卡/每日任务以版本化配置驱动；基本内容改动不改主程序。
- 开发环境 DEV 与 PLAYTEST/正式用户进度隔离；测试存档可指定首次剧情、随机种子和四个藏点，不能重复污染正常玩家进度。
- Codex Manager 负责接口和合并；Core/Gameplay/Scene/UI/QA 在任务卡界定的范围内使用 Worktree 协作；QA 需要浏览器真实验证，不把 build pass 当成可玩完成。
- 先设计剧情、美术/UI和游戏规则的交接文件，再让 Codex 执行。收费工具需逐项经用户确认。

## 本轮最新主线与玩法增补（LOCKED，覆盖冲突旧项）
- 主角是中国留学生，不固定专业或学制；前往大学的 DEMO 剧情目的为领取报到资料。
- DEMO 正式人类 NPC 仅有安娜与宿舍管理员；大学领取资料通过交互点而非新 NPC。
- HomeScene 的主要输入是拖动镜头和点击热点，不实现点击地面指令主角行走。
- 整理以格位与容量推理为基础，当天唯一固定题，可无限次重玩，跨日轮换；不采用每次进入刷新谜题。
- 猫首次摸完后必须确认名称：**摸猫反应完成时发一次性首次奖励，但 Q01 必须等 `cat.name_confirmed` 才结束**；不能以关闭/跳过命名框绕过。
- 完整剧情事件、NPC 个性、找猫 R3.2 状态、整理规则和 QA 详见 `V03_STORY_NPC_MINIGAME_SPEC_DRAFT.md`；其中标记 PROPOSED 的台词与参数需要最终策划校审。
