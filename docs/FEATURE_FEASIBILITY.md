# 功能可行性审查清单

目的：检查已确认方向与不确定的未来设想是否存在关键架构障碍。**本表是风险覆盖范围，不是本次开发需求。**

对每项按下列标签记录：`文档支持但未原型验证`、`实际原型已验证`、`高风险待验证`、`需外部依赖`、`信息不足`。说明证据、约束、最低成本实验、备选方案和决定时间。

| 系统 | 关键检查点 | 风险焦点 |
|---|---|---|
| 地图导航 | 建筑 ID、独立场景、状态、地图移动/缩放、区域扩展 | 横竖屏构图、热点坐标、返回位置 |
| 宿舍场景 | 正面看入房间、2D 图层、家具替换、遮挡、拖动物品 | 2D vs 局部 3D、触摸精度、资源成本 |
| 猫咪互动 | 藏身、寻找、重复互动、反馈、未来宠物扩展 | 可重复性与状态边界、遮挡与动画 |
| 每日整理 | 拖拽、吸附、布局规则、轻解谜、轮换随机 | 触摸适配、规则可配置、重复疲劳 |
| 其他小游戏 | 后续独立玩法、启动/完成/退出、结果传递 | 统一生命周期与不同玩法内部差异 |
| 俄语教学 | 中俄字符、字体、翻译、语音播放、情境复习 | 字体/换行、音频资源和学习反馈 |
| 高级语音（未定） | 录音、语音识别、发音评分、AI 对话 | SDK、权限、服务器、成本、隐私 |
| 剧情/NPC | 对话、条件分支、事件、场景交互 | 数据驱动、状态一致性 |
| 长期存档 | 学习记录、日常状态、版本迁移 | 更新兼容、移动端文件路径 |
| 长期玩法（未定） | 经济、商店、体力、成长、时间、地图扩展 | 不提前固化未知规则 |
| 联网与云存档（未定） | 认证、同步、服务平台 | 外部服务、成本、冲突解决 |
| 跨平台发布 | Windows/macOS/Android/iOS 构建 | 平台工具、签名、真机、设备性能 |

重点结论：识别可能造成整体重构的技术障碍和可以晚些处理的普通问题，避免把所有未知功能判为不支持或立刻开发。
