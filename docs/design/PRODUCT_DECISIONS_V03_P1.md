## LOCKED：体验和故事

1. 中国留学生初到圣彼得堡；不预设具体专业和学制。以留学生活/剧情驱动探索，自然融入俄语，不做题库网页。
2. 剧情顺序 `q00_arrival → q01_cat → q02_organize → q03_anna_message → q04_visit_university → q05_collect_pack`；猫咪和首整理由情节引导，不能靠跳对话绕过；首次解锁城市须先完成这两项。
3. DEMO 两名正式人类 NPC：安娜和宿舍管理员。大学首次进入是**领取报到资料**，不用新增第三 NPC。安娜长期朋友并参与主线。
4. 俄语 NPC 台词为主要呈现文本，**始终配中文字幕**；安娜消息同理。地图名称的中俄切换设置独立，不得关闭 NPC 中文字幕或猫咪俄语学习。
5. 首次猫咪为**西伯利亚森林猫**；可反复找猫，无关卡/星级/体力；不因答错扣除资源。
6. **完整 R3.2 交互**：先看见猫，跑往床/窗/衣柜/书桌四藏点中的一个；藏处与**俄语家具名称标签**相连（首次双语、之后俄语为主可查中文）；点击同一次尝试朗读并进行判断；正确后猫探头、连续走到可摸区域；**摸猫反馈完成后**首遇奖励只授予一次；**之后必须确认名字**，`q01_cat` 才完成。与 P0-04 直接点猫＋三藏点不同。
7. 每日整理是宿舍**独立侧边按钮**进入的生活活动，轻松收纳＋轻解谜。首次整理为必做教程；之后当天固定题、同日无限重玩、次日轮换，不是固定关卡线，也不每次随机换题。奖励是手账日期记录和少量纪念，不引入货币或装修积分。
8. 家具保留床/衣柜/书桌稳定功能槽位，窗为建筑构件；可换款式但不在当前 DEMO 做自由装修编辑器。找猫依赖对象稳定 ID 而非静态像素位置。
9. 城市正式方案为较大的圣彼得堡地图、六入口（我的小屋／大学／咖啡馆／博物馆／教堂／火车站），支持合理河道/桥梁地理骨架；大学只显示“大学/学校”及俄语，不显示真实大学全称。当前 P0 的三栋技术建筑并非正式地图内容。
10. DEMO 的较后期内容还包括 2×2 换装、手账、语言设置、任务奖励存档、试玩/开发数据隔离，分后续阶段落地；不因为 P1-01 只做部分内容就删掉总体规格。
11. DEMO 与正式版共享一套 Godot 主工程；PC 横屏、手机竖屏，使用共享场景与状态数据，允许独立屏幕布局。
12. 已被否决的 WorkBuddy 旧游戏 **没有可移植代码、美术、交互或视觉方案**，禁止复用。
