# P1 制作路线（旧 R0–R8 的 Godot 适配版）

**本包已完成 P1-00 纸面对齐；P0 代码维持原仓。不是继续旧 R0–R8 的 React/Phaser 任务号。**

| 阶段 | 重点 | 决策与产出 |
|---|---|---|
| P1-01 当前授权 | 从 P0 技术原型到首个可玩纵切片：Q00～Q03、完整首次找猫/取名、最小整理教程、城市解锁、小规模 TEMP 美术和必要本地存档 | 试玩新档能自然完成关键操作；所有源脚本和测试可回归；一份汇总 |
| P1-02 待单独授权 | Q04～Q05：正式六入口圣彼得堡地图的**功能布局**、大学取报到资料、安娜消息、可自由返回 | 不提前添加第三 NPC；正式地图构图/地理位置待制作人交接 |
| P1-03 待单独授权 | 每日整理的按自然日固定/轮换、自由重玩、奖励与手账；换装 2×2、地图双语设置等补全 | 日期/存档/幂等、题库验证、非货币奖励 |
| P1-04 待单独授权 | 玩家封闭试玩、设备触摸/安全区、语言/剧情校对与正式素材生产计划 | First Playable → Vertical Slice 质量门；独立 DEV/PLAYTEST 与 ART_PENDING |
| 以后 | 更多玩法、猫咪成长、正式美术和发行 | 由制作人另行定范围与验收，不擅自加经济或关卡体系 |

## P1 的开发与美术关系

- P1-01 允许**少量**原创/授权明确 TEMP 图层，保证体验可辨；不要求 100% 正式美术，也不应一直用无法判断趣味的纯调试色块。
- UI、猫、家具、室内构图仍是视觉候选；制作人看截图／亲自试玩后审批，不让 Codex 擅自选定长期风格。
- 真实手机实验应尽早安排；缺少手机不阻止做 PC 首段，但不能把模拟竖屏当移动版完成。

## 严格门槛

1. `BUILD_PASS`：Godot 实际启动／测试和代码满足验收要求；不是仅生成源文件。
2. `FIRST_PLAYABLE_FUNCTIONAL`：Q00～Q03 真实连玩，剧情/猫/整理/解锁/存档一致。
3. `PLAYTEST_CONFIRMED`：制作人实际亲自试玩，给出人类体验意见；如果尚未试玩，不得声称已验收。
4. `ART_PENDING`：尚未批准正式美术；临时资产不代表 RELEASE。
5. `MOBILE_PENDING`：Android 真机／iOS 未验证；不能公开宣称移动平台已通过。
