# P0-03V：正视广角宿舍构图优化与手机竖屏验证

来源：负责人本轮指令及随后天花板补充；非 P0-04。

## 目标与范围

P0-03 基本空间/遮挡已验证，但 PC 侧墙/空前景过大、手机全景偏小、默认聚焦裁两侧、调试区过大。本轮保留原灰盒与截图，有限调整房间宽深比和观察高度，不改正视广角，不重写遮挡，不改变 Godot 技术基线。

手机至少比较 A（完整房间优先）与 B（进入先全景，再简单聚焦且便捷返回）；同一房间/家具/遮挡数据，不重复建不兼容场景。调试可折叠但完整测试能力保留。三个家具、标记物、遮挡、可见热点和地图返回不得回归。不得开发正式美术、找猫、整理或装修。

## 天花板补充（并入本阶段）

建立与墙地统一透视的天花板平面，明确与后墙和侧墙的接缝；比例适当，不严重挤压家具/交互。PC 与手机均测试可见范围，对比明确天花板与弱化天花板的包围感；只使用灰盒几何，不制作灯具、灯光或正式美术。最终拼图必须有天花板对照。

## 验收与交付

回答哪种比例更接近真实舒适的生活空间；手机是否能兼顾整体认知/触摸；是否需要常驻全景/聚焦；PC/手机能否共用数据/遮挡。不得为利用画面改成俯视或等距。

对主线只交付 `docs/reports/P0-03V_SUMMARY.md`（方案、测试、Git ID、推荐）与 `P0-03V_VISUAL_REVIEW.png`（PC 原版/新版、手机原全景与两候选、天花板对照）。原始测试留项目内。完成后停止，等负责人确认，不进入 P0-04。
