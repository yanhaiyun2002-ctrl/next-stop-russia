# P0-04：可重复找猫与自然俄语互动原型

日期：2026-10-29。依据负责人本轮正式任务；授权范围仅 P0-04。

## 目标与前置

保留 Godot 4.7.2 Stable、GDScript、Compatibility，同一主工程。阅读 AGENTS、技术基线、P0-03R 汇总与风险登记，检查 Git 可回退；复用 R 宿舍、横向浏览、家具遮挡和导航，不使用旧 WorkBuddy。

视觉暂定近正视、可未来轻微俯视；本轮不要求新角度。藏点以房间坐标或对象 ID 定位，不依赖屏幕像素。

## 最小实现

- 一只几何占位猫，至少三个有效藏点；至少一个部分被家具遮挡，仍能发现与操作。
- 浏览和点击找猫，找到有明确轻松反馈，完成后再选藏点，避免相邻重复；可以无限重复和随时退出，无关卡、星级或线性通关。
- 少量与位置和行为一致的俄语，如 `Где кот?`、`Вот кот!`、`Кот под кроватью.`，允许中文释义。不随机播放无关句子。
- 区分横拖和点击；家具/猫按可见表面优先；提示不挡画布；退出和重入无残留。

## 测试及交付

保留已有导航、空间、构图和横拖回归。新增三藏点、实际位置、遮挡、成功/失败、俄语对应、连续至少十轮、鼠标/合成触摸、横竖屏和退出清理。保留真实失败与证据；桌面合成输入不是 Android 真机。
