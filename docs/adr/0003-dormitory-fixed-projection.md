# ADR 0003：宿舍固定正视透视与有限遮挡切片

日期：2026-10-28。状态：P0-03 原型采用，视觉方向等待负责人确认。

## 问题和开发前风险判断

任务要求正视广角、三家具、标记前后与家具换位。简单底边/Y-sort 会把床面、桌腿间隙、高衣柜整体当成一个平面；家具摆放或标记深度变化时易出现穿透。直接选择完整 3D 会增加模型、照明、平台和美术流程验证成本，本轮没有足够依据承担这些成本。

## 决定

保留 Godot 4.7.2 Stable、GDScript、Compatibility。世界状态放在局部 `DormitoryWorld`（Node2D），几何家具各为独立 PackedScene。投影和拾取位于 `DormitoryView`（Control/CanvasItem），UI 位于继承 BuildingRoom 的宿舍脚本。地图、BuildingDefinition、导航和学校/商店接口不变，无全局管理器。

使用固定水平视轴、眼高 1.55、镜头距前边界 3.8、焦距 780 的单点透视。Vector3 仅存几何数值；场景不含 Node3D、Camera3D 或深度缓冲。墙、地、家具共用投影。UI 对房间画布等比缩放；竖屏默认聚焦，可受约束横移并明确返回全景，共用同一家具状态。

把家具拆为有限的轴对齐盒，绘制朝向视点的正面、侧面和可见顶面。按所有盒前后深度及标记深度切开侧面/顶面，远到近绘制；同深度以顶面高度/侧面位置处理局部遮挡。标记作为所在深度的薄平面。桌腿各自成盒，空隙不会成为不可见的整块点击矩形。拾取反向遍历实际绘制多边形，只接受最上方可见表面；空间/取景变化使旧按下失效，任何释放都会清空按下状态。

家具移动只开放书桌两个合法槽位，移动接口拒绝未知 ID、越界及占地相交。这是三个样例的有限绘制方法，不是任意家具通用排序器。

## 证据与边界

`tests/dormitory_tests.gd` 独立逆投影射线与轴对齐盒求交，核对可见拾取；Windows 模式另从真实渲染图读取颜色，核对物体归属。实际截图和完整数字见唯一主线报告 `docs/reports/P0-03_SUMMARY.md`，不能把测试通过视为负责人已确认画面。

正式贴图仍需按同一视点、尺寸、地面锚点、前后遮挡层与透明空隙生产；当前独立家具场景/几何合同可替换，任意单张插画不能直接获得正确遮挡。旋转家具、复杂曲面、动画肢体互穿、相交摆放、镜头转动、多层透明均未验证。出现这些明确需求时再对一个局部复杂样例比较遮挡遮罩和局部 3D 成本。本轮不自动进行该实验。
