# ADR 0004：宿舍内短生命周期找猫

日期：2026-10-29。状态：P0-04 原型采用，玩法体验待负责人确认。

## 开发前可行性与风险判断

R 已有稳定家具 ID、房间坐标、固定投影、有限深度切片及可见面拾取，可承载三个有限藏点。直接使用屏幕坐标或覆盖家具的整块猫按钮会在镜头移动后漂移或穿透；新宠物管理器、完整 AI 和存档并非验证本次循环所需。移动端触摸、字体与细小目标仍须真机和真人检查。

## 决定

`CatHunt` 为宿舍 world 持有的 RefCounted，状态仅搜索/找到及本次提示、计数。三藏点存稳定 ID、家具 ID、Vector3 偏移和中俄对应文本。猫锚点实时由家具地面位置加偏移计算；下一次在其余两个藏点中随机选择，找到后由显式“再找一次”触发，不添加关卡或持久成长。离开宿舍随场景释放，重入是新搜索。

`GrayboxCat` 返回房间坐标的身体/耳朵/头/眼睛/尾巴平面，床下头部在身体前方露出；只使用几何占位。将猫各深度纳入已有家具切片边界，复用原排序和反向可见多边形拾取。家具遮挡的猫身仍归家具，露出的头才可点击；不做穿透热点或自动放大命中框。原橙色标记在空间测试模式下恢复。

沿用 R 的横向意图、10 逻辑单位阈值、拖动抑制点击及几何变化取消输入。仅在原释放判断通过后，空白点击增加局部失败反馈。点击家具不移动镜头；具名导航按钮只浏览，不替玩家找到猫。提示和结果置于画布外同一个固定最小高度区域，不覆盖主要场景。

测试面板展开时暂停并隐藏猫，恢复旧标记测试；收起继续同一搜索。横向预设可选找猫/空间测试，V 预设只回放旧空间。R 回归显式选择实际可用的空间模式，保留全部旧断言；新套件测试真实默认找猫入口和普通按钮连续十轮。

## 角度与扩展边界

ADR 0003 的固定水平观察是历史实现决定，不是永久视觉约束；负责人现在允许近正视和未来轻微俯视。本轮未改投影。改角度可复用藏点 ID 和坐标，但几何薄平面、头身分深度、可发现面积及位置语义需重验；不能据此承诺任意角度和美术直接适用。任意新家具/旋转/遮罩、音频和真实设备性能仍未验证，不新增框架。

## 证据

实际像素、独立射线/房间平面深度、三藏点、五尺寸、拖点冲突、十轮与退出测试见 `tests/cat_hunt_tests.gd` 和 P0-04 汇总。首轮合成触摸偶发失败及后续复测原样保留；通过不能替代真机或真人体验。
