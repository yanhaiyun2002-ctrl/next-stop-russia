# 项目风险登记表（更新至 P0-03R）

P0-03R 更新：根据本地视频关键帧，验证较宽连续空间、几何窗/分区/顶梁和默认手机局部横拖。取景为固定投影画布平移，尺度不变、无惯性；端点同时约束室内背景与主要家具，点击/横拖使用 10 逻辑单位阈值，窗口/取景变化取消旧手势。视频只提供视觉依据，不能证明源引擎、触摸阈值或惯性。桌面合成触摸、像素与逐帧数学检查不替代真机、真人体验或性能验收。后续增加家具、物理视差/镜头转向需要另验边界和分层成本；本轮不泛化摄像机。实际失败、修复和建议见 [P0-03R_SUMMARY.md](reports/P0-03R_SUMMARY.md)。

P0-03V 更新：收窄房间、降低眼高、延长固定水平视点距离、以家具/后墙界定全景取景，减少空侧墙和前景；天花板与墙地共享投影，PC/手机均有明确/弱化顶面对照。手机 A 保持全景点选，B 先全景再点选聚焦；具名按钮至少 48 逻辑单位，调试默认折叠。实际测试与对照图见 [P0-03V_SUMMARY.md](reports/P0-03V_SUMMARY.md)。小屏完整房间仍受横向宽度限制，细桌腿直接触摸与真人操作负担未验证；本轮不代表真机或视觉方案定稿。

P0-03 更新：固定正视透视、三件轴对齐几何家具、两个书桌槽位的有限切片遮挡已完成原型；独立射线/可见面拾取和 Windows 像素检查通过，横竖屏使用同一空间状态。具体数字和截图见 [P0-03_SUMMARY.md](reports/P0-03_SUMMARY.md)。这降低了 R06 在当前样例内的不确定性，不代表任意旋转家具、角色动画、美术遮罩或移动 GPU 已验证。竖屏全景家具偏小，需要聚焦取景；负责人仍须根据截图确认视觉方向与操作负担。

P0-02 更新：已用确定性实验修复尺寸变化期间接受旧热点输入的问题，增加按下取消、同一时刻快照与有界状态等待；最终 Headless 254/0、Rendered 连续五轮各 268/0。历史渲染失败的逐事件原因不能全部从旧日志重建，连续通过不等于不存在偶发故障。证据统一见 [P0-02_SUMMARY.md](reports/P0-02_SUMMARY.md)，P0-01 收尾为历史记录。

平台风险更新：Windows 独立测试包实际运行 17/0；Android 调试 APK 构建、签名与包内资源检查通过，最终匹配 Build-Tools/Platform 36。Android 设备/模拟器为空，实际触摸、安全区、后台恢复、性能仍阻断该平台发布。macOS/iOS 无 Apple 主机/签名/设备，未验证。原生 UI 手工操作通道因沙箱辅助进程初始化失败不可用，保留为人工复核缺口；没有将合成 GUI 输入当作真人或真机操作。下表中工具链初始缺失的描述为 P0-01 历史状态，最新结果以本段及 P0-02 汇总为准。
