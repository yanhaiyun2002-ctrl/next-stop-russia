# P0-03R：参考视频校准、横向宿舍与手机拖动原型

来源：负责人正式 P0-03R 指令。仅视觉/交互技术原型，不进入正式美术或 P0-04。

## 前置与目标

阅读 AGENTS、P0-03V 汇总与 ADR；实际检查 `docs/references/dorm_visual_reference.mp4`，必要时取帧，分开记录明确特征与推断。保留 V Git 基线、测试和成果；不把视频美术/模型/动画当游戏资源。

继续正面看入室内，强调广角、前中后景和生活空间，不以单帧完整六面体为目标。当前主工程做横向连续宿舍，三家具/标记保留，可调整位置/占地；允许几何窗、分区、顶面和层次。不要求复制斜顶、装修风格或功能。优先复用 V 遮挡，若有新限制先记录再做最小修复。

## 手机最高优先级

默认大比例局部；横拖浏览左右，合理边界无空白；点击/拖动明确区分；连续投影、不漂移；家具可读可操作；简单复位；顶/地协调；UI 不挡主要区域并验证模拟安全区。不做复杂缩放、惯性、跟随或编辑。

PC 展示较宽视野，可受约束平移，检查空间比例、层次、顶地、盒子感、家具与 UI 可读性。PC/手机同一数据、不同取景，不改俯视或等距。

## 约束、回归与交付

Godot 4.7.2 Stable、GDScript、Compatibility 不变；地图、学校、商店、导航不改。执行已有核心回归，新增边界、点击/拖动冲突、移动热点、层次、方向、返回/重入及小屏验证；记录真实失败，不删旧断言。合成触摸不是 Android 真机。

不做正式美术/装修/购买/找猫/整理/剧情/NPC/俄语/换装/复杂动画/完整 3D，不造大型管理框架，不用 WorkBuddy，不推送远程。

主线仅交 `docs/reports/P0-03R_SUMMARY.md` 与 `P0-03R_VISUAL_REVIEW.png`；拼图至少有 V 原版、新 PC、手机左中右、新家具遮挡，真实渲染、标状态、等比、不美化。日志/截图保留项目。完成后停止等负责人确认。
