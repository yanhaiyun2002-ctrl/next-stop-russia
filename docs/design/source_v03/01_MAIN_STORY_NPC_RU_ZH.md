# 第一章 DEMO 剧情与俄中对白规格（V0.3）

更新：2026-10-27。**产品决定 LOCKED；具体台词与节奏为 PROPOSED，需要制作人最终文案确认。** 不代表已配音或已开发。

## 1. 语言呈现规则（LOCKED）

- **俄罗斯 NPC 的台词以俄语为主显示，始终提供对应中文字幕。** 中文是辅助字幕，不要求俄罗斯角色在故事中实际说中文。
- 安娜消息同样保留俄语原文与中文字幕；玩家内心独白与系统教程可使用中文主文案，俄语家具词汇仍保持教学展示。
- 文本是独立 `dialogueId`，不烧录进插画。字体必须支持西里尔字母；不同语言在手机端应自动换行。
- 俄语语音可由可复用音频资产或正确设置 ru-RU 的试听功能提供；**DEMO 不强制完成所有 NPC 配音**。若语音不存在、浏览器不允许自动播放或朗读失败，字幕照常前进。点击朗读不应重复触发剧情。
- 地图语言显示模式 `both|zh|ru` 与 NPC 中俄字幕分开管理，切换地图语言不得隐去故事中文字幕和找猫俄语标签。
- 俄文已按常见表达拟写，但属于剧情文案候选；正式上架前仍应进行一次目标语言校对。本阶段不要求逐句外部审核，不阻塞机制规格。

## 2. 主线事件序列（LOCKED 的行为合同）

| Quest ID | 场景和触发 | 前置条件 | 最终完成事件 | 备注 |
|---|---|---|---|---|
| `q00_arrival` | 简化抵达→安娜引导→管理员交钥匙→HomeScene | 新存档 | `story.home_entered` | 跳过演出仍必须持有钥匙并认识两 NPC |
| `q01_cat` | 首次猫出场→四处之一藏身→家具标签识词→走出→摸猫→**强制命名** | 进入 HomeScene | `cat.name_confirmed` | 摸猫后奖励可先落盘，但 **Q01 只能在命名确认后完成** |
| `q02_organize` | 引导侧栏独立「整理」→教程题 | Q01 已完成 | `organization.tutorial_completed` | 必做，且不能靠跳过对白绕过 |
| `q03_anna_message` | 安娜发送资料提醒→开放出门和城市入口 | Q01、Q02 完成 | `story.city_unlocked` | 消息与解锁可幂等重放 |
| `q04_visit_university` | 玩家拖动地图→点击「大学 / Университет」 | 城市已开放 | `story.university_arrived` | 无主角全城寻路；不显示真实大学全称 |

每一项最终事件进入统一剧情系统；不得将具体 UI 点击次数作为主线完成条件。对话可以跳过，但 Q01 猫咪互动、取名和 Q02 整理不可跳过。

## 3. 逐句对白候选（PROPOSED）

以下俄语是 NPC 实际呈现主文本，中文是同步字幕；每一条应单独配置 `dialogueId`。每段建议短，避免移动屏幕被长文字占满。

## 4. NPC 关系层（LOCKED 方向；默认状态设计 PROPOSED）

`anna`: `not_met → acquainted`；`dorm_admin`: `not_met → acquainted`。以后安娜可以通过共同剧情变为 `friend`；DEMO 不建立可刷好感度，也不因不回消息扣友情。

## 5. 文案交付协议

每条本地化记录至少有 `id`, `speakerId`, `ru`, `zhSubtitle`, `voiceAssetId?`, `blocking`, `presentation`。字幕不可用或资源缺失时采用文本回退并记录缺项，不可阻塞剧情。严禁把俄语文本绘进家具/地图素材。
